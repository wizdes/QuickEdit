## Nodes

### n1: app icon (plan: 3 drafts, root picks one, the user can swap later)
difficulty: medium
owns: QuickEdit/Resources/QuickEdit.icon (new), QuickEdit/Resources/icon-drafts/ (new: the three SVG drafts and renders), project.yml (icon setting only)
steps:
  1. Three SVG drafts that say "fast plain text": for example a page with a lightning-quick cursor, a bold "Aa" on lined paper, a text caret on a clean sheet. macOS 27 icon grid and rounded square. Render each at 1024 and 32 px with WebKit (Kelpi trap: NSImage drops shadows, qlmanage adds white) and look at them.
  2. Root picks one. Build it as an Icon Composer `.icon` that actool compiles (the Kelpi pattern in Projects/Kelpi/app/Resources/Kelpi.icon), so macOS 27 does not show a gray plate. Set the app icon in project.yml.
     verify: Release build; `iconutil` or the asset catalog output holds the icon; a Dock or Finder render looked at
