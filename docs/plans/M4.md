### n2: Select Line panel
difficulty: medium
owns: QuickEdit/Window/LinePanelController.swift, QuickEditTests/LinePanelTests.swift, QuickEditUITests/FindAndLineTests.swift
steps:
  1. Port `LinePanelController` in code (no nib): a small panel with the prompt "Enter a line number or a range of line numbers to select." (exact strings from `reference/apple/English.lproj/LinePanel.strings`), one text field, Select button. Accepts `N`, `N-M`, `N:M`, and `+N` / `-N` relative forms if TextEdit 1.9 does (check the .m and report). Line counting uses `NSString.lineRange(for:)` from the start, so CR, LF, CRLF, U+2028 and form feed all end a line. For speed, count lines with a byte scan of the storage string's UTF-16 buffer (not repeated `lineRange` calls) and stop at the target line. Invalid input shows TextEdit's message and beeps.
  2. The panel is created on first use only; it remembers its frame (window restoration, like TextEdit's three panels).
     verify: unit tests for parsing and selection on LF, CRLF, CR and mixed text, last line without a trailing newline, out-of-range; a 100 MB fixture-sized string (build it in memory) selects line 1,000,000 in under 200 ms in a Release-optimized test (`measure` block, report the number)

## Hands-on script for the user
1. Cmd+F, type a word, Cmd+G a few times; Opt+Cmd+F and Replace All.
2. Cmd+L, type 20, Return: line 20 is selected.
3. Edit > Transformations > Make Upper Case on a selection.
4. Taste question: do the menus feel the same as TextEdit's?
