QuickEdit Settings: Keyboard tab, three mockups

Each window is drawn at true size: 1 pixel on a Retina Mac is 1 point, so the windows are 440 pt wide, like the real Settings window. All 59 commands come from MainMenu.swift, with their real keys.

At the start, every mockup shows the same moment: the user clicked the shortcut of Save to record a new one, then pressed ⌘O. That key belongs to Open…, so the tab refuses it and says why. Print… was changed earlier to ⇧⌘P, so it shows a reset button.

You can try them. Click a shortcut, then press keys. Esc cancels and Delete removes the shortcut. The browser keeps some keys for itself, such as ⌘W, ⌘Q and ⌘Tab, so those may not reach the mockup.

A. One flat table

Like System Settings App Shortcuts. 11 pt small type, 18 pt rows, every command in one list with a header row per menu.

  • Good: every command is in one list, so you can scan it for a free key, and about 22 rows fit on screen.
  • Good: the 11 pt type matches the small controls on the two TextEdit tabs; the message line under the table never covers rows.
  • Bad: the small rows are hard to read and click, there is no search, and 70 rows mean a lot of scrolling.

B. Search plus an outline

13 pt type, 24 pt rows. Menus are disclosure groups, and Edit has nested groups for its submenus. The clash message is a popover at the field.

  • Good: the search finds a command by name or by key (type "⌘S" or "save"), so 59 commands stay fast to reach.
  • Good: closed groups keep the list short, and the popover puts the message right where the user is looking.
  • Bad: closed groups hide commands, Edit needs two clicks to reach Find, and the popover covers the rows under it.

C. Pick a menu, see only its commands

13 pt type, 32 pt rows, keys drawn as key caps. A pop-up on top picks the menu. The message opens inside the row.

  • Good: the fewest and largest rows, so it is the easiest to read and click; key caps make each key clear.
  • Good: the message stays inside the row being changed, and a button opens the macOS keyboard settings.
  • Bad: you must know which menu holds a command, you cannot see free keys across menus, and Edit is still 31 rows.
