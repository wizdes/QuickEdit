Architecture delta · QuickEdit M8 · speed and very large files

Opening a big file, before and after

Before, QuickEdit read the whole file into one more copy and filled the text on the main thread. Now a file over 50 MB is cloned first, the reader checks the clone in place and fills the text in 8 MB pieces off the main thread, and a file over 512 MB opens read-only (vote V3). For a 1 GB file the window freeze went from 384 ms to 52 ms and peak memory from 2,133 MB to 1,144 MB (builder's measurements).
