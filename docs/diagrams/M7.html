PDF output, before and after

The user chose PDF output only (decision U1). Before, Print and Page Setup went through the macOS print system, which contacted the print helper and made macOS ask for local-network access. Now QuickEdit draws every PDF page itself. Print helper connections went from 1 to 0 (measured in the system log).
