What the sandbox lets through, and how a new shortcut lands

M9 turns on the App Sandbox, a macOS rule that keeps an app inside its own folder unless the user hands it a file. The signed Release app carries exactly two entitlements (permission keys): com.apple.security.app-sandbox and com.apple.security.files.user-selected.read-write. M9 also adds a Keyboard tab in Settings, where the user can change the key for any menu command QuickEdit builds (user decisions U2 and U4).
